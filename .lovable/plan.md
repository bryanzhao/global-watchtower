# 全球安全风险监测平台 · 首版方案

## 需求理解

一个面向内部分析师的全球安全风险监测工作台（客户简化版留待后续）。核心结构：

- **四类信源**（不是四个固定源，而是四类可按议题自由组合的信源类型）
  1. 社交媒体情报（Twitter/X 等）
  2. 主流媒体定向检索（固定关键词/媒体清单）
  3. 权威专家与机构（顶级学者、智库、投行、咨询公司清单）
  4. 自建 OSINT 定制信源
- **两种研究组织方式**
  - 风险频道：战争冲突、恐怖袭击、政治动荡、骚乱示威、社会治安犯罪、自然灾害、传染病
  - 专题研究：针对具体事件/国家的持续跟踪（如俄乌冲突、美伊冲突、利比亚国别、美国对古巴军事行动风险）
- **产出**：每日简报（A4 可打印公文格式）
- 信息流由你方另行建设，本站只需在数据模型和界面上预留 API 接入位；AI 自动分析本版留占位，人工分析师标注流程走界面。

## 首版交付（4 个核心页面 + 打印简报）

1. **全球风险总览（/）** —— KPI 指标条（活跃预警数、高风险国家数、24h 新增事件、待研判条目）；全球风险等级分布表；按风险类型的频道枢纽卡；今日重点事件表格；四类信源接入状态条。
2. **信息流工作台（/feed）** —— 分析师主界面。左侧筛选（信源类别、风险类型、地区、风险等级、时间、研判状态），中间信息条目列表（标题、摘要、来源、时间、语言、原文外链），右侧详情面板：AI 分析占位区（自动摘要 / 风险评级 / 实体识别，标"待接入"）+ 人工研判区（风险等级、可信度、关联频道/专题、分析师批注、采纳进简报）。
3. **风险频道（/channels 与 /channels/$slug）** —— 频道列表页 + 单频道页（该风险类型的态势摘要、地区风险表、时间线、绑定的信源组合、相关条目）。
4. **专题研究（/topics 与 /topics/$slug）** —— 专题列表 + 单专题页（专题概况与关键判断、时间线、关键行为体、情景推演占位、关联条目、专题报告入口）。
5. **每日简报（/brief）** —— A4 打印友好公文：报头（标题、日期、数据截止时间、来源统计）、全球风险概要、分风险类型要点、重点事件、专题进展、附录来源列表；打印时隐藏导航与交互控件。

导航：总览 / 信息流 / 风险频道 / 专题研究 / 每日简报。

## 视觉执行

严格按你提供的设计规范落地（把"疫情监测"换成"全球安全风险监测"）：

- 在 `src/styles.css` 用 oklch 定义规范中全部 token（含新增 `--success`、`--warning`、`--warning-foreground`、`--surface`），并在 `@theme inline` 注册；组件内不出现硬编码颜色。
- 白底 + 深海军蓝主色 + 警示红点缀；无渐变、无阴影、一律 1px 描边；圆角 `rounded-sm`/`rounded-md`。
- 系统字体栈（纯中文界面），数字 `tabular-nums`；排版层级按规范表执行。
- 布局 `max-w-[1400px] px-6 py-8`；sticky `h-14` 顶栏 + 底部风险色状态条。
- 图标 `lucide-react`，只用 `transition-colors`，无位移/缩放动画。
- 风险三档配色按规范；颜色 + 文字标签双重表达，保留 focus-visible 焦点环。

## 技术说明

- TanStack Start 文件路由，页面：`index.tsx`、`feed.tsx`、`channels.tsx` / `channels.index.tsx` / `channels.$slug.tsx`、`topics.*`、`brief.tsx`，每页独立 `head()` 中文标题与描述。
- 共享组件：`PageShell`、`SiteHeader`、`KpiCard`、`RiskBadge`、`SourceBadge`、`DataTable`、`FilterBar`、`EntryDetailPanel`、`PrintHeader`。
- 数据层：`src/data/` 下集中 TypeScript 类型 + 演示数据（`SourceClass`、`RiskType`、`FeedEntry`、`Channel`、`Topic`、`BriefSection`），字段结构按未来 API 接入形态设计，后续换成真实接口时只替换数据获取层。
- 本版不启用后端、不接 AI；AI 区域以明确的"待接入"占位呈现。
