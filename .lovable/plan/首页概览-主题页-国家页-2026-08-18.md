# 首页概览 + 主题页 + 国家页

在现有「原始信息流 → 风险信息流」生产链路之上，增加面向浏览与研判的三层入口：全局概览首页、重大主题详情页、国家详情页。所有数字与条目都从已确认的风险信息流（RiskEvent）派生，不引入新的数据来源。

## 1. 首页 `/`（原工作台移到 `/raw`）

左右分栏（左约 2/3 地图，右侧竖排主题卡片，窄屏自动上下堆叠）。

**左：六边形网格世界地图**
- 抽象蜂窝布局：每个国家/地区一个六边形，按大区聚成块（欧洲、中东、非洲、南亚、东亚、美洲、大洋洲），保留大致地理相对位置，不画任何边界线，规避争议边境。
- 六边形填色 = 该国过去 24 小时风险事件的最高等级（低/中/高，用现有语义色）；格内显示事件数字。
- 支持滚轮/双指缩放与拖拽平移（缩放 0.6×–4×），右下角 +/− 与「复位」按钮；hover 出浮层（国家名、24h 事件数、按风险类型分布），点击进入国家页。
- 顶部图例 + 时间窗切换（24 小时 / 7 天）。

**右：重大风险主题卡片**
- 卡片内容：主题名、风险等级徽标、一句话当前局势概览、关键指标（近 24h 新增事件数、涉及国家、主导风险类型）、最近一条事件摘要、「AI 生成 · 更新于 08-18 06:00」时间戳与刷新按钮（本阶段仅更新时间戳，文案为预置内容）。
- 首批主题：俄乌冲突、美伊对抗、萨赫勒/非洲政变观察、非洲传染病观察、美国-古巴、红海航运。
- 点击进入 `/topics/$slug`。

首页下方补一条「全球风险速览」条：24h 事件总数、高风险国家数、按风险类型的分布条。

## 2. 主题详情页 `/topics/$slug`

统一骨架 + 每个主题可插拔的定制模块，兼顾原则性与灵活性。

通用骨架（所有主题都有）：
1. 主题头：名称、等级、状态标签（升级中/僵持/降温）、最后更新时间、一句话判断。
2. 关键判断（3–5 条要点，带置信度 A/B/C）。
3. 主题事件流：从风险信息流按 `topic` 过滤的时间线，可按风险类型/国家/等级筛选，条目可展开看溯源原始信息。
4. 关键行为体：国家行为体 / 组织 / 个人，来自事件结构化字段的聚合，点击国家跳国家页。
5. 情景与触发指标：2–3 个情景（升级/维持/缓和）+ 每个情景的观察指标清单。
6. 时间轴里程碑（人工维护的慢变节点）。

定制模块（按主题声明式配置，只渲染声明过的模块）：
- 俄乌冲突：战线/州级态势表（前线区域 + 近期活动强度）、军援与制裁动态、能源与粮食走廊影响。
- 美伊对抗：代理人网络（真主党、胡塞、伊拉克民兵等）活动强度、核计划与谈判节点、海峡与航运风险、美方兵力调动信号。
数据用现有 mock 结构扩展，`TopicProfile` 里以「模块类型 + 数据」的形式声明，新增主题时只写配置。

## 3. 国家页 `/countries/$code` 与列表页 `/countries`

列表页：全部国家按当前风险等级排序，可按大区与风险类型筛选，显示 24h/7d 事件数。顶栏增加国家搜索框（全局可用，键入即筛选，回车进入）。

国家详情页：左右分栏。
- 左（主）：该国动态信息流 —— 已确认风险事件时间线（AI 编辑/人工确认标识、风险类型筛选、可展开溯源）。
- 右（侧栏，分块）：
  - 国别风险总览：总体等级 + 概述段落（慢变，标注「人工维护 · 最近修订 2026-06」）。
  - 七类风险类型赋值：每类给 1–5 分与等级色条 + 一行说明。
  - 重点关注实体：机构、武装组织、关键人物、关键设施。
  - 基本盘分析（慢变）：政治体制与稳定性、安全部门、经济与社会、外部关系，折叠展开。
  - 关联主题：该国涉及的主题卡片链接。

## 技术方案

- 路由：`src/routes/index.tsx` 改为首页概览；现工作台迁到 `src/routes/raw.tsx`；新增 `topics.$slug.tsx`、`countries.index.tsx`、`countries.$code.tsx`。顶栏导航更新为：概览 / 原始信息流 / 风险信息流 / 国家，并加搜索框。
- 地图：手写 SVG 六边形网格组件 `src/components/platform/HexWorldMap.tsx`，坐标表放 `src/data/hexmap.ts`（axial 坐标 + 国家码），不引第三方地图库。缩放平移用原生非被动 `wheel` 监听 + 指针拖拽，滚轮按 `Math.exp(-dy*k)` 缩放并锚定光标位置。
- 数据：新增 `src/data/topics.ts`（TopicProfile 与定制模块类型）、`src/data/countries.ts`（国别慢变档案 + 风险赋值）；给 `RiskEvent` 增加 `countryCode` 便于地图与国家页聚合。派生统计（24h 计数、类型分布）用 `useMemo` 从 workbench 的 `events` 计算，保证与风险信息流一致。
- 每个新路由各自的 `head()` 元数据；沿用现有 OKLCH 语义色，不新增硬编码颜色。
