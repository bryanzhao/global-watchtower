# 重构方案：原始信息流 → 风险信息流

推翻此前版本，只保留生产过程的两个页面。删除总览、风险频道、专题、预警、每日简报及其组件。

## 页面一：原始信息流工作台（/）

顶部标签切换四类信源，四类信息互不混合：
社交媒体 / 主流媒体 / 权威机构与专家 / 自建 OSINT。

每个标签下：

- 二级筛选：风险类型（战争冲突、恐怖袭击、政治动荡、骚乱示威、社会治安、自然灾害、传染病）、所属主题（俄乌冲突、美伊冲突等，可为空）、时间范围、处理状态（未处理 / 已提取 / 已忽略）。
- 主体是典型时间线：按时间倒序，左侧时间轴刻度 + 时间戳，右侧条目卡（信源账号/媒体名、正文摘要、语种、原文外链、已打的类型与主题标签、处理状态）。
- 顶部有"刷新"按钮与"最近更新时间"，模拟持续刷新（点击后向时间线顶部插入若干新条目）。
- 每条前面有复选框。勾选任意条数后，底部出现操作条：`已选 N 条` + `提取为风险事件` + `忽略` + `取消选择`。
- 单条也可直接点"提取"，等价于只勾选它一条。

## 提取抽屉（结构化录入）

点"提取为风险事件"后打开抽屉，左侧列出被选中的原始条目（可再移除某条），右侧是结构化表单，AI 预填（本版为规则预填，标注"AI 预填 · 待接入"）、分析师可改：

- 事件标题、事件概况
- 发生时间（可为时间段）
- 地点：国家 / 地区 / 城市（可多选国家）
- 人物与主体：国家行为体、组织机构、当事个人（可自由增删标签）
- 风险类型、风险等级（高/中/低）、可信度（A/B/C）
- 所属主题（可为空）
- 溯源：自动带上所选原始条目的 ID 与链接

提交后：这些原始条目状态变为"已提取"，并在条目上显示关联的事件编号；新事件进入风险信息流。

## 页面二：风险信息流（/risk）

- 同样是时间线，但每条是结构化风险事件卡：等级色条 + 标题 + 时间 + 地点 + 类型/主题标签 + 概况摘要 + `来源 N 条`。
- 筛选：风险类型、等级、国家、主题、时间。
- 点击展开/进入详情面板：完整结构化字段 + 涉事主体清单 + 溯源原始条目列表（可跳回原始信息流对应条目）+ 编辑与"补挂条目"入口（本版补挂从事件详情里选择近期条目）。

## 技术说明

- 纯前端演示数据，无后端。`src/data/` 重写为：`RawItem`（含 sourceClass、author、text、publishedAt、lang、url、riskType?、topic?、status、eventId?）与 `RiskEvent`（结构化字段 + sourceItemIds）。
- 提取/忽略/合并通过一个 `src/state/workbench.tsx`（React context + useReducer）在两个页面间共享内存状态；刷新页面回到初始演示数据。
- 路由：`src/routes/index.tsx`（原始信息流）、`src/routes/risk.tsx`（风险信息流），各自独立 head() 中文元信息；`__root.tsx` 导航改为两项。
- 视觉沿用现有设计规范 token（白底 + 深海军蓝 + 警示红、1px 描边、无阴影无渐变、tabular-nums），复用 `PageShell`、`RiskBadge`、`Primitives`。
- 删除：alerts / channels / topics / brief 路由与 `AlertComposer`。
